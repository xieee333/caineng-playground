# 彩能游乐场

一款正在设计中的动漫风格多人 PvP 派对射击游戏：用怪枪打斗、用技能移动、用炸弹和场景物件制造有来有回的意外。

## 从这里开始（2026-09-21 更新）

- **先理解怎么玩：** [新版详细设计](docs/superpowers/specs/2026-09-21-party-shooter-design.md)。不需要开发经验。
- **看先做什么：** [开发路线](docs/ROADMAP.md)。
- **看现在做到哪：** [进度](docs/PROGRESS.md)。
- **准备使用 UE：** [UE 实施准备与阶段计划](docs/superpowers/plans/2026-09-21-ue-party-shooter.md)。

新版建议：第三人称、先 4 人后 6 人、6 分钟计分混战、快速复活。首轮包含两把枪、短冲刺、三件道具和一张可交互地图。具体数值与视角是原型验证方案，并非已经实现。

当前仓库以设计和概念资产为主，尚未创建 UE 工程。2026-09-18 的 Unity 路线、先做六把成品枪和最后才联网的执行顺序已被新版替代。

## 历史方向（2026-09-18，供追溯）

当时的设计方向：

- 彩能喷射、钻地、上墙、弹跳和短时滞空
- 非致命的击退、吸附、冻结、绑缚和道具互动
- 轻量公共目标，不以击杀或硬性争夺为唯一胜负条件
- 狂欢事件、玩具化枪械和多维度正向结算
