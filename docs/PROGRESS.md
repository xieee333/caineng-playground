## 2026-09-21 变更

- 核心从可选公共目标和巡游表演转向怪枪计分混战，保留轻松风格和快速复活。
- 明确不加入拳击/摔跤核心系统；加入趣味炸弹和场景反制。
- 首轮内容收敛为 4 人、2 把枪、短冲刺、3 件道具、1 张地图。
- 联网由原路线末期提前至 P1；旧 Unity 计划保留为历史记录。
- 第三人称、具体数值与 UE 版本选择都标明为方案或验证项，没有冒充用户已锁定的决策。
- 本次仅修改文档；不报告引擎编译、游戏运行、联机或性能测试通过。
- 文档检查：当前入口与两份新文档的本地 Markdown 链接检查通过，`git diff --check` 通过；引擎技术方向已对照计划末尾的 Epic 官方资料。
