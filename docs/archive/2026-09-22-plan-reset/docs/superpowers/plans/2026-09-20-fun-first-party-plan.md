# 彩能游乐场：乐趣优先的整合计划

日期：2026-09-20。执行顺序更新；具体模式、角色名称和能力是待原型验证的提案，不代表已实现或最终定稿。

## 1. 定位与已确认约束

定位改为 **3v3 社交型动作派对游戏**，而不是传统 FPS 加一个搬运球。明确目标负责把人聚在一起，角色、玩具枪、场景和玩家之间的强互动负责持续制造合作、反制、整蛊和可复述的局内故事。枪法只是一种表达；路线、时机、接应、机关、欺骗、救援和临场配合都能决定胜负。轻松不等于无脑，搞怪不等于幼稚。

用户已明确：娱乐性与可玩性优先；角色、枪体应有区别；命中人、地形、物件产生不同结果；天马行空但不幼稚；正式 UI、美术需用户确认；换人物和枪械模型尽量不重写玩法；修改后必须验证。

保留喷涂移动、非致命交互、快速回场及武器与技能组合。新增硬约束：不会玩 FPS 的玩家不能只是被保护对象，必须能通过接球、铺路、救援、机关、近距宽判定工具、诱骗和团队连携主动影响胜负。目标也不能与技能、武器分离，每一种首发工具都必须能直接改变核心、携带者、路线或得分窗口。

不能靠计划保证好玩：自动化证明规则，机器人证明运行，真人重复试玩才提供乐趣证据。

## 2. 核心循环与首个模式

发现目标 → 选择自己能做好的事情 → 与队友制造机会或对敌人设局 → 武器、能力、核心和场景产生连锁 → 对手反制/队友救援 → 得分或快速回场 → 下一轮尝试新组合。

首个验证模式仍用 3v3 单核心争夺，但规则重心改为“**创造一次团队得分演出**”：双方把核心送入己方装置，核心可被传递、弹射、吸回、减重、截停和借机关改道；携带者不能独自完成所有事情，队友的铺路、救援和控场具有直接价值。远程发射采用距离、速度和入门判定限制，不能一枪跨图获胜。先验证一套足够深的互动网络，不并行堆护送、占点、生存。

### 三种同样有效的参与方式

| 玩家偏好 | 能做什么 | 对胜负的直接价值 |
| --- | --- | --- |
| 喜欢瞄准与追击 | 精确截球、打断关键动作、利用反弹角度 | 制造掉球和反攻窗口，但没有爆头秒杀 |
| 不擅长 FPS | 用扇形/范围工具铺路、吸回核心、启动机关、近距救援 | 稳定接应、改变路线、把失误救回来 |
| 喜欢社交与捣蛋 | 诱骗、假动作、协力弹送、反用敌方布置、保护队友 | 让对局产生信息差和组合技，而不是只在旁边看 |

基础瞄准采用宽容判定：无爆头倍率；多数控制工具为近距、扇形、范围或软锁定；核心与可互动物拥有比角色更宽的命中辅助。高手仍能通过角度、时机和移动拉开差距，但新手不会因为准星不稳而失去参与资格。

先试每小轮 2–3 分钟、数轮组成一场；原先 6 人、6–8 分钟可作为整场预算。人数、队伍与计时仍待验证。欢乐称号表彰救援、巧妙反制等行为，但不替代明确胜负。自由玩耍区作为练习，不承担核心循环。

当前第一人称仍是实现基线。早期做第一/第三人称小对比，检查角色可见性、瞄准、空间判断和眩晕后提出建议，不擅自切换定稿。普通鼠标移动应直接转视角。

## 3. 三个角色原型：区别在做事方式

以下名称仅为机制工作名，正式人物设计另行确认。

| 原型 | 独有能力与身份 | 反制与限制 |
| --- | --- | --- |
| 潜相者：隐形潜入 | 短时低可见潜行，可穿过标记为可相位的薄墙，从侧后方突袭或干扰物件 | 移动有轻微扰动，近距离及被命中可识别；出墙有预告与短暂攻击前摇；携带目标时禁用，不穿任意墙 |
| 回弹者：操控动量 | 蓄力定向脉冲，截下物件、推开来敌、协助队友弹送 | 蓄力可见，可侧移/借掩体；冲量有上限，不连控；强友方发射需主动配合 |
| 拟像者：制造误判 | 投影重复最近短动作，诱骗射击或掩护转移 | 近距离可辨、命中揭穿；数量和寿命受限，不能推进目标、不伪造系统 UI |

所有角色共享基础移动和武器资格，不强制坦克/治疗配队。先每人一个核心主动能力，小被动仅有必要才加。差异不能只是速度/血量变化，也不能有全面占优的万能角色。

角色不是“输出/辅助”的固定职业。每个角色都必须同时拥有：一个独自能制造机会的动作、一个能与队友形成连携的动作、一个对手可看懂并反制的破绽。这样不会玩枪的人可以靠角色能力参与，也不会沦为只能跟在高手身后的工具人。

### 新增需求：潜入、穿墙与整蛊（用户提出，参数待测试）

- 潜相者替换首轮折相者的位置，不额外扩成四角色；折跃通路保留在后续候选池。
- 首版候选参数：潜行最多 4 秒、冷却 12 秒、一次技能最多穿一处指定薄墙；出墙后约 0.4 秒才能攻击。参数不是承诺，依据双方体验调整。
- 潜行不是无敌：受击显形，射击/用攻击道具主动结束隐形；脚步、近距离折射或墙面波纹提供追踪机会，不允许无预警贴脸无限控制。
- 出口必须通过完整胶囊体积、地面与边界检测；无安全出口则停在入口侧，不扣成功穿墙次数。不使用全局关闭碰撞，不进入封闭墙体、地图外或出生保护区。
- 携带目标、泡泡化及比赛结束时禁用；若以后允许携物潜入，必须另外验证，不能借隐形跳过争夺。
- 整蛊首先服务局势：绕后截球、把敌人布置的弹射点反用、投影诱骗、悄悄改变小物件位置。贴纸/音效属于可选表现，不挡视野，不羞辱玩家，也不代替策略。
- 必测：潜入者与受袭者两端提示、受击/攻击显形、墙厚和斜角、出口被占、技能中回场/结束、连续尝试、冷却、网络延迟下的位置权威。机器人验证安全，真人验证惊喜是否大于挫败。

角色与武器分工：角色决定何时、从哪里介入，枪体决定主要交互动作。例如回弹角色侧重临时防守与改向，弹射枪侧重预先布置。换外观不能改变碰撞优势。

## 4. 枪体、配件与命中对象

枪体决定动作，配件改变一个可理解的行为。不开放无限叠加；先三类工具，再扩展既有六枪内容池，不废弃旧设计但不一次承诺全做。

| 工具原型 | 命中人物 | 命中地形 | 命中可移动物件 |
| --- | --- | --- | --- |
| 充气 | 短时减轻重量、易被推走，仍可移动射击 | 生成有寿命/次数的气垫 | 小物件浮起，重物只减重；目标核心单独限值 |
| 弹射 | 下一次落地小弹跳，有预告且能通过动作消耗 | 生成方向明确、双方可利用的弹射点 | 改变方向/弹性，不无限增能 |
| 吸附 | 短促牵引，可借掩体脱离，不长时间拖拽 | 建立局部吸附锚点 | 聚集/吸回小物件，核心有牵引速度上限 |

这些是待验证规则，不是现有功能声明。可复用现有 Bloom、表面与泡泡机制，但须检查其与目标循环是否相容。

组合示例：充气减重 → 弹射送出 → 对手吸附截回。趣味来自可理解的因果与反用，不是每发子弹随机惩罚。

统一约束：控制叠加上限、短时保护、回场保护、视觉预告及解除途径。禁止黑屏、反转鼠标、强转镜头和连续长硬直；不挡关键视野；不允许无限欺负队友。冲量、状态、目标归属由服务器裁定。

### 队友与对手都能“操作你”，但结果不同

同一工具命中队友和敌人时遵守同一物理语言，但强度、意图和保护不同：

| 互动 | 命中队友 | 命中对手 | 彩蛋/连锁 |
| --- | --- | --- | --- |
| 充气 | 给出可接受的轻量弹跳/救场，可用移动输入拒绝强推 | 短时变轻、脚步发飘，更容易被环境推开但仍能行动 | 两个充气角色相撞会互相弹开；携带者只受弱效果，核心掉落后可被吹走 |
| 弹射 | 队友主动跳跃或按配合键时获得强弹送，否则仅小推 | 下一次落地弹起，提前显示落点方向，可用空中操作修正 | 队友空中接到核心形成“空投传球”；敌人也能反用弹射板逃脱 |
| 吸附 | 将落崖/被围队友拉回安全方向，强拉需要队友确认 | 短促牵引或打断蓄力，掩体可阻挡 | 两边同时吸核心会触发短暂“拔河”，胜负取决于位置和时机而非连点 |
| 潜相/拟像 | 队友可替潜相者制造假脚步或用投影假装接球 | 对手可通过命中、近距扰动和入口波纹识破 | 投影接到“假传球”会继续跑两步后碎裂，骗出一次关键工具 |

所有强友方位移默认需要轻量同意：队友主动跳跃、按配合键，或处于落崖/泡泡救援状态才会放大效果；否则只能产生不会破坏操作的小推力。连续被同一来源操作会迅速衰减，并提供短时保护。任何彩蛋都不能改变鼠标方向、遮住主要画面、长时间夺走控制权或把队友永久困住。

### 命中反馈不是纯装饰

- 角色受击后产生 0.4–1.2 秒的可操作状态变化，例如变轻、弹跳印记、短促吸附；玩家始终能移动、转向或用明确动作化解。
- 地面、墙、核心和场景小物件使用相同的效果语法，因此玩家能预测组合，而不是记忆随机笑话。
- 稀有彩蛋由两个以上可理解条件触发，例如“充气 + 弹射”“投影 + 假传球”“双方吸附拔河”；彩蛋会改变局势但不直接判胜负。
- 每局结算记录“神救援、妙传、反用机关、骗招成功、绝地截球”等社交时刻，避免只展示击中数或击杀榜。

### 社交体验边界

- 快捷信号以“想接球、拉我、送我上去、这里有埋伏”为核心，不要求语音也能配合；后续可选近距语音，但不是玩法成立的前提。
- 鼓励朋友互相搞耍，但队友不能扣分、长控、反复推下地图或阻断出生；重复骚扰触发衰减和保护。
- 对手整蛊必须带来“我知道发生了什么、下次能反制”的感觉。幽默来自局势反转和人物反应，不来自羞辱失败者。
- 中途加入、新手和低准度玩家应在 30 秒内找到至少一种有价值的动作；复杂组合由反复游玩自然发现。

## 5. 不幼稚的美术与幽默边界

沿用用户指定中间绿发人物的整体方向：帅气日漫面部与发束、潮流街头科幻、清楚轮廓、风格化体积。参考不是照抄，也不是所有角色同一绿发少年。避免全员婴儿比例、糖果塑料感、满屏表情贴纸与尖叫音效。

幽默来自情境：精心布置被反用、漂亮传球被截、救援顺带触发机关。人物仍有魅力与能力，不靠装傻或羞辱失败者。夸张动作可用，但不牺牲操控清晰度；不以沉重、暴力替代成熟感。中文命名与提示统一。

首张图先做中央目标区、两条侧路、一处高低差，最多两类互动机关。路标明确、画面留白，背景暗线后置，不能抢占交战信息。正式 UI、人物、场景美术需用户确认；当前只改必要的原型可读性。

### P3：三角色 × 三工具

- [x] 潜相者首个原型：指定薄墙、安全出口、受击/开火/到期显形、服务端验证；持球禁用与 0.4 秒出墙攻击前摇已接入回归。
- [ ] 逐角添加，先单独测试再测工具组合，一次只改少量变量。
- [ ] 落地人/地形/物件差异，统一效果叠加、优先级、保护与清理。
- [ ] 落地队友同意、连续操控衰减、救援放大和出生保护，先封住恶意队友与连续失控。
- [ ] 至少实现三种可复述连锁：空投传球、核心拔河、假传球骗招；每种都有明确反制。
- [ ] 换第二套明显不同的人物和枪械占位模型验证表现适配，记录真实成本，不承诺任意骨架零成本。
- 门槛：玩家能描述各角色擅长什么；有不同有效策略；无必选万能组合。

### P4：重复试玩，决定删改

- [ ] 同批真人至少连续五轮，再与新玩家交叉试玩；缺人数明确写样本不足。
- [ ] 记录目标理解、无事可做时间、连续失控、选择角色理由、输后感受和主动再开意愿。
- [ ] 第 1/3/5 轮分别问还有什么想试、最烦什么、想换角色是为玩法还是仅外形。
- [ ] 分开记录救援、拦截、路线策略与偶然搞笑，不用欢乐值代替反馈。
- 门槛：无奖励诱导也愿再来，数轮后仍有具体新尝试，被捉弄方仍知道如何应对。小样本只指导迭代，不证明长期留存。
- 不通过则针对原因修改：无目标改节奏，重复改互动/路线，烦躁缩控制增反制，角色弱改独特用途。不能默认多枪多图就会好玩。

### P5：通过核心后再扩展与发行准备

- [ ] 逐把接入既有六枪与配件，验证是否新增策略；再加地图机关、有限公开事件和角色。
- [ ] 事件提前提示，不随机判胜负；不以永久战力成长强迫重复游玩。
- [ ] 用户确认 UI/美术后推进正式资产，完善动画、声音、可访问性与性能。
- [ ] 目标人数压力、延迟、加入/退出/重连、服务器异常和多人滥用测试。
- [ ] 明确发行平台、设备预算、授权与服务成本后列发行验收，原型通过不等于可上架。

## 7. 每次改动的证据规则与下一步

规则测试 → 构建 → UE 游戏内运行 → 相关流程回归 → 记录结果。注明 PIE/独立运行、真实人数和时长；构建、探针、手操与真人乐趣证据分开。失败修复后重测，不把预期填成实测。

下一步先验证“工具直接改变核心”的首条链路，并补上队友/敌人差异与防骚扰规则；随后完成传接球、路线收益和 Bot 分工，再按“充气 → 弹射 → 吸附”做三工具垂直切片。第一批必须能形成空投传球、核心拔河或救援中的至少一种，而不是只做三把不同伤害数值的枪。持续推进 P2 双端状态。需要真人参与、正式美术/UI 或最终视角选择时明确提出，不虚构已经确认。玩法数据、网格/骨架、动画、音效/VFX 分层，第二模型替换测试作为复用能力验收。
