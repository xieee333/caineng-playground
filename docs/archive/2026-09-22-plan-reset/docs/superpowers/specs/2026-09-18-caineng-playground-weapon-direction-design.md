# 彩能游乐场：波普漫画武器方向规格

## 目标

把枪械从“换皮射击武器”变成角色风格和玩法的延伸：每把枪在第一人称画面中都有独立轮廓、独立动作和独立声音；命中后优先改变空间、移动和环境，不依赖精准爆头或高伤害。

当前美术基线是 v11 波普漫画 2D：粗黑线稿、印刷网点、青/洋红错位色层、夸张透视、漫画冲击线和扁平背景。枪械必须服从同一套视觉语法，同时拥有比人物更夸张的“主形状”。

## 1. 设计原则

1. **一眼认出**：缩小到 64 像素轮廓后，玩家仍能区分六把枪。
2. **像玩具和街头艺术，不像军火**：不使用现实枪械的完整比例、弹匣和瞄具结构；弹药仓被替换为花瓣、唱片、气球、线轴或灯笼等可读部件。
3. **枪改变空间**：每把枪至少有一个移动、表面或道具效果，伤害只是低权重的打断反馈。
4. **动作就是卖点**：开火、换形、过热和特殊技都要有明显的机械展开动作，配合网点、速度线、纸片、星爆或贴纸式特效。
5. **低门槛**：基础射击使用宽容的命中体积和轻度吸附；特殊技的价值来自制造路线和连锁反应，而不是准星速度。
6. **可变形但不堆数值**：词条改变枪的形状、弹道和互动方式，优先改变观感与玩法，不做永久战斗数值碾压。

## 3. 枪械词条与变形规则

词条不直接提供永久攻击力，而是改变枪的一个可见部件、一个交互参数和一套特效。每把枪最多同时装备三条，保证读图和测试边界清晰。

| 词条 | 外观变化 | 玩法变化 |
|---|---|---|
| **泡泡** | 枪口增加半透明气泡仓和圆形高光 | 命中后目标更容易漂浮，适合救援和空中捣乱 |
| **折射** | 枪身出现棱镜片和错位色边 | 投射物获得一次额外反弹，反弹角度有明显预览线 |
| **磁吸** | 侧面出现旋转磁环 | 轻型道具会被吸附到弹道附近，方便做连锁反应 |
| **传导** | 枪身增加发光线缆和电弧贴纸 | 彩能线可以短暂连接两个表面，扩大移动路线 |
| **弹簧** | 枪托、花瓣或尾翼替换为机械弹簧 | 互动结果获得更明显的弹跳和回弹，但不增加硬控时长 |
| **镜像** | 枪身出现成对的镜面贴片 | 产生一个短时假弹道或假枪口，降低对手判断压力 |

变形分三档：基础形（无词条）、混合形（两条词条改变枪身）、狂欢形（三条词条在狂欢事件期间展开完整形态）。狂欢形只持续一局内的短时事件，不形成永久强度差距。

## 4. 每把枪的资产交付标准

每把枪在进入 Unity 前必须完成以下资产，避免只做一张好看的立绘：

1. **轮廓板**：正面、侧面、第一人称持枪视图、64 像素黑色剪影。
2. **动作板**：待机、开火、换形、特殊技、过热或冷却五个关键姿态。
3. **玩法卡**：基础射击、特殊技、可影响的目标、解除方式、低瞄准门槛说明。
4. **视觉反馈表**：颜色、图案、粒子、命中音、特殊技音和 HUD 图标。
5. **Unity 预制体**：枪身占位、枪口点、投射物点、VFX 挂点和 `WeaponDefinition` 数据。
6. **验收记录**：独立轮廓识别、非精准命中可玩、至少一种环境连锁、不会永久卡住玩家。

## 5. 建模与 2D 表现路线

### 5.1 第一阶段：2D 概念与占位

先用概念图、剪影和简单几何占位验证轮廓、视野占比和开火动作。这个阶段不制作高模，也不把时间花在不可见的细节上。

### 5.2 第二阶段：第一人称低模

只为确定进入垂直切片的枪制作低面数模型：大轮廓用简单几何，材质使用平涂、粗描边、网点贴图和青/洋红偏移，不使用写实金属和真实枪械磨损。模型的职责是承载动画和碰撞，不改变 2D 波普观感。

### 5.3 第三阶段：2D 角色与背景统一

角色使用 2D 分层插画或轻量 2D 骨骼；背景使用扁平层、少量视差和漫画面板。枪械是第一人称画面中最接近镜头的视觉锚点，因此优先把枪的轮廓、动画和特效打磨到可读。

## 6. 开发顺序

1. **武器视觉规范**：冻结六把枪的轮廓、颜色、玩法和词条规则。
2. **第一把枪垂直切片**：先实现棱花喷绘器，验证喷射、铺面、弹跳和第一人称手感。
3. **数据驱动枪械框架**：用 `WeaponDefinition`、`ToyWeaponController`、`InteractionResolver` 让枪械参数可替换。
4. **剩余五把枪**：按“每枪一套概念资产 + 一套测试 + 一个预制体”的顺序接入。
5. **角色技能和公共目标**：把枪械效果接入六人混战、泡泡重生、欢乐值和狂欢槽。
6. **视觉统一与反馈**：统一网点、错位色层、命中图标、音效和漫画冲击线。
7. **本地六人原型**：本地玩家加五个 Bot，先验证娱乐性和可读性，再评估网络接入。
8. **联网与发布包装**：仅在本地循环稳定后接入网络同步、房间流程和构建配置。

## 7. 验收标准

- 玩家在不看 HUD 的情况下，仅凭枪身轮廓和开火特效能区分六把枪。
- 新手只使用基础射击，也能通过宽容命中和环境互动制造有效结果。
- 每把枪至少有一个改变移动、表面或道具的非伤害玩法。
- 六把枪的特殊技都能在 3 秒内看懂，强控效果有预告和解除方式。
- 任何枪械都不会因为一次命中让玩家长时间失去操作权。
- 词条改变外观和交互方式，不形成永久数值碾压。
- 画面保持 2D 波普漫画观感，枪械没有写实军事化外形。
