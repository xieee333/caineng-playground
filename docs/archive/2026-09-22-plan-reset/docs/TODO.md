## 产品方向

制作一款第三人称、精致风格化 3D 多人游戏。首轮是 4 人、6 分钟的设备对抗：矢量脉冲器和相变凝胶枪既能直接战斗，也能改变掩体、路线或攻击机会；角色移动异能、道具和场景互动形成可反制的连锁。玩家快速复活，不会被淘汰后长时间旁观。完成首轮后再做异常试跑、4–6 人验证和公网交付。

首轮明确不采用 3v3 搬运核心、潜相穿墙、六枪喷涂、狂欢轮盘或 72×52 米搬运竞技场作为正式玩法目标。它们可以留作旧原型诊断，不进入新方案验收。

## 每轮执行纪律

1. 先对照 [迁移映射](MIGRATION_TO_ANOMALY_DISTRICT.md) 确认碰到的是新代码路径还是旧诊断路径。
2. 每个阶段先完成规则与依赖，再改实现；只改本阶段需要的系统。
3. 记录实际源码、构建/测试命令、游戏内结果、失败和未验证边界；不要把旧 18/18、旧搬运局或图像截图说成新方案通过。
4. 真人乐趣由真实玩家验证；Bot 对局仅证明规则、路线或节奏数据。
5. UI 方向需要用户确认时，停在可观测灰盒和最小信息 UI，不替用户定稿。
