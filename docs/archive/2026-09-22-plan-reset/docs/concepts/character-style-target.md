# 游戏角色美术目标：绿发角色整体风格参考

记录日期：2026-09-20。

## 用户明确的需求

用户指定下图**中间的绿发人物**，以其整体风格作为游戏人物参考。参考对象不包括后方机器人、右侧人物或整张图的场景。用户原话：“整体的，然后作为我游戏的人物参考风格（是中间那个绿发的）”。

![用户提供的角色参考](character-style-reference-greenhair-2026-09-20.png)

结合此前要求：人物要有日漫特征，男主要帅；减弱写实、光滑塑料和过强的 3D 渲染感，保持清晰的动漫轮廓和五官表达。此图作为新的角色整体造型参考，优先于旧文档中尚未落地的“角色必须使用 2D 分层插画/骨骼”制作假设。具体渲染方案需用 UE 样片检验。

## 从参考中提取的执行标准

以下是对图片的设计解读，用于制作第一版提案，尚不代表具体新角色已经定稿。

| 部位 | 制作目标 | 检查方式 |
|---|---|---|
| 整体气质 | 日系动漫与潮玩造型结合，有少年感、个性和俏皮神态；保持帅气，避免幼儿化 | 正面、侧面和四分之三视角均能读出相同气质 |
| 头身与轮廓 | 头部有适度夸张，身体和手部简化；保留清晰的发型、领口、袖口与配件轮廓 | 原图只有半身，不据此写死头身比；全身草案比较比例后再确定 |
| 面部 | 较大且有明确上眼线的眼睛，清楚的瞳孔高光，小巧简化的鼻嘴，干净的脸颊与下颌 | 中性光下仍能辨认神态；不依赖写实皮肤、毛孔或强鼻影 |
| 头发 | 参考灰绿/薄荷绿的分组发束、侧分刘海、蓬松与外翘轮廓；发束有方向和层次 | 用块面与少量明确阴影表现，不以密集写实发丝替代造型 |
| 服装 | 街头科幻感的短外套、内搭、手套和少量醒目配件；大结构优先 | 黑白剪影下仍可辨认；细节集中在领口、袖口和一个主配件 |
| 配件 | 头顶护目镜是参考中的识别点，可借鉴“一个大配件形成角色记忆点”的方法 | 新角色使用原创配件结构，不要求每个人都戴同一副护目镜 |
| 材质与光照 | 保留模型体积，面部与头发采用柔和、简化且分区明确的阴影；金属服装可以有光泽 | 银色外套强反光属于参考特征；第一版尝试压低细碎反射，避免脸和头发呈湿亮塑料质感 |
| 线条 | 优先保证眼线、发束分界与外轮廓可读，描边粗细用 UE 镜头测试决定 | 不把“全身统一粗黑边”当成已经确认的要求 |

绿发、绿眼、护目镜、银色外套是参考特征，**不是所有角色必须照搬的固定装备或配色**。新角色需要自己的身份、配色和服装设计；先保留整体造型语言。

## 与游戏的衔接

- 角色需适合彩能游乐场的跑跳、喷绘、夸张武器和轻松混战；远看轮廓清晰，近看表情有辨识度。
- 第一人称优先验证手臂、手套、袖口与玩具武器的搭配；第三人称全身供其他玩家、Bot 和角色展示使用，两者风格一致。
- 美术网格、材质、骨架适配、动画与挂点由独立视觉档案配置；更换外观不复制移动、技能、命中和得分逻辑。
- 不同骨架仍需要重定向和握持/脚底/配件挂点适配；用第二套不同体型的占位模型检查实际替换成本。
- UI 美术仍需另行与用户确认。本记录确定角色参考方向，不代表 UI 或场景风格已经定稿。
