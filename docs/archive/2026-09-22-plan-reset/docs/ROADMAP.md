## 原有基线方向（按最新计划调整）

玩法整体按既有设计规格重写。官方 First Person / Shooter 模板仅作为输入、相机和引擎工程起点；模板的射击、击杀/比分、武器循环、中继试炼都不是最终核心循环。旧中继关卡可保留为教学或诊断内容，不再作为主线里程碑。

目标是 6 人、6–8 分钟一局的第一人称欢乐混战：喷涂改造移动表面，靠移动路线、玩具武器、主动技能、轻量公共目标和共享狂欢事件制造连锁互动。非致命控制优先，泡泡化约 3 秒快速回场；结算按多种欢乐行为颁发称号，不用击杀数/涂色面积作为唯一胜负依据。UI 美术、正式角色和场景模型暂缓，先完成可玩规则与可观察的原型反馈。

权威玩法规格：[`设计规格`](superpowers/specs/2026-09-18-caineng-playground-design.md)、[`武器方向规格`](superpowers/specs/2026-09-18-caineng-playground-weapon-direction-design.md)。

## 重写原则

- 新规则与模板表现分离：规则核心无世界依赖，Actor/组件负责 UE 表现，数据资产定义武器、技能、角色外观和效果参数。
- 角色外观与移动/能力分离；武器玩法定义与网格、骨架、动画、VFX 分离。换一套完全不同的模型不应重写核心规则；特殊骨架只需独立适配/重定向表现层。
- 所有玩家与 Bot 走相同移动、喷涂、命中、得分和事件接口；Bot 验证功能回归，最小真人联机提前验证娱乐性，正式联机服务与规模化后置。
- 先实现液态、弹跳、飘浮三类表面；接口预留黏性、镜面、传导。效果短、可读、可解除，不做永久战力成长。
- 每个可玩切片都需规则自动化测试、编译、PIE 观察和可复现操作记录。构建通过不等于游戏内体验通过。

- [x] Ctrl 地面液态潜行原型：真实胶囊/速度/视点变化、松键恢复、液态消失退出、低矮通道安全站起；七阶段可见开发演示通过，规则 12/12。
- [x] 液态墙攀爬初版、松键/墙面失效下落、空格蹬墙、墙上受击回场；十二阶段可见联合回归通过，规则 13/13。
- [ ] 墙角连续移动/墙顶衔接、复杂障碍与多人预测；完成真实键盘长按、纯鼠标观察与完整跑跳路线验收。正式液态化动画/外观后置。
- 喷涂状态网格/可喷表面、液态潜行与加速、弹跳面、飘浮/滑翔；统一玩家与 Bot 移动命令。
- 明确地面、空中、潜行、泡泡等移动状态，支持救援、击退和环境连锁。
- 完成门槛：PIE 中可稳定移动、喷涂、潜行、弹跳、滞空；边界和重生状态测试通过。

### R4 — 比赛循环、技能与公共目标

- [x] 棱花 E“盛放”初版：弹射玩家与轻型物体、冷却保护、泡泡禁用与到期消失已在真实 UE 运行中通过。
- [ ] 其余五武器特殊玩法、盛放跨角色/多人表现与复杂场景安全边界。
- [x] 泡泡期间停止连发、拦截新开火与技能；旧伤害耗尽生命改走泡泡回场。实际受击测试约 3.22 秒回场且欢乐值不变。
- [x] 潜相原型：仅穿标记薄墙，安全出口校验，短暂隐匿，开火/受击破隐，8 秒冷却；规则与真实地图探针通过。正式角色绑定和表现待做。
- 6–8 分钟自由混战；约 60 秒自由探索后滚动出现可忽略的公共目标。
- 六种主动技能：炮弹化、墙内藏身、位置交换、彩能反转、召唤宠物、超级喷射。
- 欢乐值、目标参与、救援/连锁/路线等多维正反馈；不是击杀排行榜。
- 完成门槛：至少一个公共目标完整完成/超时；泡泡重生约 3 秒且不丢永久资源；结算人人有称号。

### R5 — 狂欢事件与六人本地原型

- 低重力、彩能狂喷、气球雨、巨型生物、场景旋转、烟花派对事件池。
- 20–30 秒事件可开始、同步状态、结束并恢复原规则；至少三种进入首个可玩版本。
- 本地玩家 + 5 个可复现 Bot 共用正式玩法接口，跑完 6–8 分钟一局。
- 完成门槛：一局至少经历两次可感知变化；低瞄准门槛下仍可通过环境/协作/捣乱获得乐趣。

### R6 — 多人权威验证

- [x] 最小双端基线：第二客户端连接监听服务器，搬运 G 输入 RPC 由服务器裁决，拿取/抛出及复制快照一致；潜相 X 请求由服务器验证墙体/出口，显隐状态双端一致。
- 在本地循环稳定后，测试两端移动、表面状态、武器效果、目标、事件、泡泡回场和断线处理。
- 服务端/权威端决定命中与状态；客户端预测仅用于手感和视觉效果。
- 完成门槛：两客户端对关键状态一致；之后才扩大内容量。

### R7 — 可玩性打磨、正式美术/UI 与交付

- [x] 记录用户指定的中间绿发人物整体风格，并保存原图；执行标准见 [`角色美术目标与 TODO`](concepts/character-style-target.md)。方向为日系动漫与潮玩造型结合，保留立体体积、减弱写实渲染感；全身比例和具体原创角色尚待样片确认。
- [ ] 按角色目标制作原创男主三视图、表情和第一人称手臂提案，再在 UE 检查面部、发束、服装反射及持枪搭配；确认后制作正式模型。
- 先和用户确认 UI 美术方向；之后统一角色/武器/场景/特效/音效。
- 内容资产采用可替换的网格、骨架适配、材质与表现配置；玩法数据不绑死模型。
- 性能、输入、打包、设置、新手体验和发行流程按目标平台验收。
