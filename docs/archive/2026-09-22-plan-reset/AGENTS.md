## 必读顺序

1. 完整读当前v0.3设计与 `docs/MASTER_PLAN.md` 的最新入口：后者下方v0.1只作工程历史，不是当前产品目标。
2. 读 `docs/PROGRESS.md` 并检查 Git 状态与实际文件：确认真实进度。
3. 根据当前任务读总纲链接的世界、枪械、资产或 UE 专项，不能只凭总纲摘要实现细节。

## 核心约定

- 工作名“异常街区”，仓库名 caineng-playground。精致风格化 3D 发明家与异常科研社区；旧二维动漫、波普漫画、v11 视觉基线全部失效。
- 两把主枪都能独立打斗，也能通过有代价、有反制的功能改变战局。不加入拳击/摔跤核心。
- 首轮四人设备对抗；再做试跑和六人验证，不同时生产所有扩展内容。
- UE 是当前工程路线，Blender 是主要资产加工工具，Hyper3D 是可选初稿生成工具。
- 基础攻击与本枪特殊功能共享本枪能量；两枪互相独立；角色异能使用第三个独立资源池。具体规则分工见总纲。
- 原型初值可以在测试后调整，不能擅自把低压力多人游戏改成排位、养成商城或大逃杀。

## 执行与交接

- 本入口建立时只有文档与历史概念图，没有 UE 工程、新风格成品模型或已通过的联网测试。后来状态看 PROGRESS 和实际产物，不凭文档勾选推断。
- 保留用户未提交修改。新机器核实 UE/Blender 版本、插件、工具调用能力、参考图和生成额度，不假定本机已有。
- 原参考图来自临时路径；没有永久副本时按资产流程处理，不用旧图代替，不伪称看过缺失图片。
- 文档任务不授权自动付费生成、上传素材或安装软件；实施授权按当前用户任务判断。
- 下一工程任务以最新 `PROGRESS.md` 和 `TODO.md` 为准；勿重复把已验证工程当成尚未开始。每项完成都记录文件、实测、未验证事项和下一步。
- 当前规则按总纲第 13 节分工维护。仓库只保留当前方案 Markdown，不从 Git 历史恢复旧设计作为实施依据。
- 不写进度假象：本地提交不是推送成功，模型下载不是验收成功，本机测试不是公网测试。
