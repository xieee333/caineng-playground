# 异常街区开发路线

> 当前基线 v0.1。完整规则与任务见 [总纲](MASTER_PLAN.md)，实际进度只在 [PROGRESS](PROGRESS.md) 更新。本文件是路线摘要。

| 阶段 | 交付 | 通过条件 |
|---|---|---|
| P0 环境 | 版本记录、UE 模板、LFS、打包与干净检出 | 实际可打开、运行、打包，记录缺项 |
| A0 美术支线 | 人物设定、同屏样张、单件模型生成/加工/导入试验 | 新参考画风成立，记录质量、费用和工时 |
| P1 双人闭环 | 移动、射击、生命、计分、复活、结算重开 | 两进程一致，模拟延迟下无重复结算 |
| P2 两枪战斗 | 基础攻击、切枪资源、推力、弹性地块、冲刺 | 空场能打、有机关有更多选择、双方可反制 |
| P3 道具互动 | 三道具、回扔、打偏、桥板、容量/连控限制 | 关键互动反复测试，无穿墙、复制或无限控制 |
| P4 四人试玩 | 灰盒研究站、房间、HUD、贡献判定、三局反馈 | 至少两位新手能理解规则，记录反制与再玩意愿 |
| P5A 美术切片 | 一人物、两枪、三道具、场景、动作/音效/VFX、缓降 | A0 通过后制作，UE 中外观和功能成立 |
| P5B 试跑模式 | 检查点、排序、换模式、最小标记/表情 | 10 次模式切换无状态泄漏 |
| P6 公网交付 | 跨网络会话、4～6 人、性能、Windows 测试包 | 公网真实测试，机器配置与已知问题可查 |

A0 可在 P0–P4 间进行，不阻塞不依赖参考图的灰盒工作；P5A 前必须通过。P4 乐趣未通过就回 P2/P3 修改，不用更多资产掩盖问题。

后续候选：第二角色、极性线圈枪、折射轨道枪、联合抢修、带代价的词条。每次选择一个单独验证，未进入首轮。

工程具体步骤见 [UE 计划](superpowers/plans/2026-09-21-anomaly-district-ue.md)，资产步骤见 [资产规范](assets/ASSET_PIPELINE.md)。完成 P0/P1 后按真实工时估算日程，当前不承诺未经验证的日期。
