# 异常街区｜首个完整交付版计划

更新：2026-09-22。依据 [总纲](MASTER_PLAN.md)。最新确认B方向：枪械属性主导玩法，不要求喷涂；此前固定的样本封存、残像与伏贴组合不再是执行清单。

## 1. 范围

一张精做小地图，两把属性明显不同且能独立对抗的枪，一个支持枪械的辅助技能，一个简单完整模式，必要UI/模型/动作/音效/特效，2–4人私人房间，独立Windows包。先双人后3/4人，单人仅练习。

两枪、辅助技能和胜负规则通过切片确定；弹性/牵引是候选，不是已锁定。暂缓复杂经济、运输、藏组件、多角色、第三枪、更多地图、商城、公开匹配、语音。人物先一套统一基型，用明确标识区分玩家。菜单不显示未实现假功能。

## 2. 当前最先要做

- 审计矢量/凝胶实际行为与联网，提取可复用部分，不强行保留原武器身份。
- 对比候选属性，每个写清基础攻击、对人/环境效果、反制、资源代价与反馈。
- 在同场景测试单枪与双枪。不依赖额外奖励，观察是否主动试招、反制和换用法。
- 选两种差异明显的有效体验，再比较简单争夺目标与直接对抗基线，锁一种模式。
- 选择增强枪械的辅助技能，不让去掉枪后仍基本能完成整套玩法。
- 集中确认UI、枪体、角色与场景同屏视觉，不先批量生产资产。

记录候选、证据、结果、理由。方向性取舍再沟通；未发生真人试玩或用户确认，不得写成已通过。

## 3. 操作与架构

基础输入：WASD、鼠标直接转向、跳跃、冲刺、换枪、基础射击、属性操作、技能、交互、菜单。动作可重映射，键位在切片固定，不能右键才能转向。死亡/失焦/菜单/结算取消持续输入并正确恢复鼠标。

本地手臂与远端模型分离；准星与枪口都验证遮挡，不能隔墙射击。服务器裁决生命/能量/冷却/命中/状态。武器稳定ID和配置共用基础入口，特殊属性独立实现。交互对象白名单明确，位移效果共用防连续控制规则。

UI绑定状态，不硬编码枪名；地图设施可摆放，不把坐标写死角色。测试配置接入装备与HUD、替换地图对象、换测试模型验证扩展能力，不先开发万能编辑器。

## 4. 美术和UI

同屏提案包括第一人称枪体、对手、维修街景、HUD，以及房间和结算。方向为清楚动漫轮廓、柔和分区阴影、克制反射，不杂乱/幼儿化；颜色随最终属性确定。用户确认后批量制作，未确认可继续技术线框但不能定稿。

首版资产：角色与手臂，两枪模型/握持/切换，少量建筑模块和互动对象，命中/属性/失效/能量/技能/复活反馈，以及相应音效。先走通单件导入、碰撞、动画、材质与性能样板，再复制流程。采购和外部上传需授权；许可和来源纳入交付记录。

| 界面 | 必须内容 |
|---|---|
| 主菜单 | 练习、创建、加入、设置、退出、版本 |
| 房间 | 成员、准备、开始/离开、连接状态、必要配置 |
| HUD | 准星、生命、当前/备用枪、能量/属性状态、技能冷却、目标与时间 |
| 上下文 | 有效操作、无效原因、属性反馈，不暴露敌人私有信息 |
| 设置 | 灵敏度、音量、画质/分辨率、按键保存 |
| 结算 | 权威胜负、并列处理、重开/离开，不伪造精彩事件 |

检查中文字体许可/缺字、1080p/1440p与宽屏、枪体遮挡。状态不用颜色或声音单独表达。练习引导可跳过可重看，不能只有外部说明。首包不得停在静态方块枪和调试文字屏。

## 5. 地图与完整比赛

一处中庭、形成环路的街巷、可达阳台和少量明确互动对象。根据枪属性安排路线与表面，关键点至少两条普通路线；尺寸按遭遇密度实测，不先追求大。

模式选定后在本文补齐胜负、计时、并列、权威计分、死亡/复活保护、断线与局末清理，再实现正式模式。不得直接套用旧击败分或封存规则。流程从菜单到房间、准备、比赛、结算、重开不需要控制台。

出生不被唯一出口堵住，重开清理状态；房主离开明确返回或提示，不假称主机迁移。比赛中加入者首版等待下一局。

## 6. 批次

| 批次 | 工作 | 输出 |
|---|---|---|
| A | 工程审计、属性筛选、同屏提案 | 可核实基线与候选，用户确认视觉 |
| B | 单枪/双枪对抗、属性反馈、必要场景 | 打人有用、环境用途清楚、可反制、双端一致 |
| C | 基于双枪确定目标和技能，菜单/房间/结算 | 完整回合，枪械不可有可无 |
| D | 已确认UI、资产、动作、声音、引导设置 | 同屏统一，无关键占位/缺字/遮挡 |
| E | 3/4人、性能、错误恢复、干净电脑、打包 | 完整Windows目录与证据 |

美术与功能并行，不等D才开始。独立模块可并行，共享角色/模式文件由整合负责人控制。规则优先自动测试，同批合并构建；Computer Use只集中验证操作、镜头和表现。网络在相关里程碑验证，不逐参数重复长测。

真人试玩覆盖FPS新手和熟手，记录枪械主动使用、反制、唯一套路、空档和再玩意愿；Bot/脚本不能证明好玩。
