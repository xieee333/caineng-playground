更新日期：2026-09-20。本文是当前开发任务的唯一执行清单；`PROGRESS.md` 记录已发生的事实，`ROADMAP.md` 说明阶段结构，详细玩法规则见 [`乐趣优先的整合计划`](superpowers/plans/2026-09-20-fun-first-party-plan.md)。

## 产品北极星

做一款 3v3 社交型动作派对游戏。枪法不是唯一能力：瞄准、铺路、接应、救援、机关、诱骗和整蛊都应直接影响胜负。每种强互动都必须可读、可反制，并防止队友长期夺走他人控制权。

当前原型模式为单核心争夺；它是验证互动网络的载体，不是已经锁定的最终模式。正式 UI、人物、武器和场景美术在玩法达到对应关口后与用户确认。

## P0：当前必须完成——强互动核心

### T01 统一社交操控规则

- [ ] 抽出队友、对手、自身三种关系判定，不在各枪械里重复写逻辑。
- [ ] 队友普通命中只产生弱推；队友主动跳跃、按配合键或处于救援状态时允许强弹送/强拉回。
- [ ] 同一来源连续操控快速衰减，并在强控后提供短时保护。
- [ ] 禁止反转镜头、黑屏、长硬直、出生区骚扰和无限推落地图。
- 验收：规则测试覆盖友方同意、拒绝、救援、敌方命中、重复命中衰减和保护结束；玩家始终可以转向并恢复操作。

### T02 完成“工具 × 目标”互动矩阵

- [x] 弹射场景能力能改变松散核心。
- [x] 牵引风筒能以宽锥判定吸回松散核心。
- [ ] 充气/轻云使核心短时减重或延长传球距离，到期恢复且不遗留质量错误。
- [ ] 回旋/弹射改变核心方向，但总速度不超过上限。
- [ ] 携带状态、得分瞬间、重置期间拒绝物理工具影响。
- 验收：每种工具分别命中玩家、地形、普通物件、松散核心并产生可预测结果；服务器负责状态和速度上限。

### T03 传球、接球与掉球争夺

- [ ] 增加明确的传球意图，不让抛球和丢弃共用模糊结果。
- [ ] 队友处于接球范围且面向来球时使用宽容接球判定；敌人仍可截球。
- [ ] 传球失败、碰墙、受击和越界都能进入可争夺的松散状态。
- [ ] HUD 仅增加原型提示：可传对象、来球方向、接球成功/被截，不做正式 UI 美术。
- 验收：完成一次普通传球、一次空中接球、一次敌方截球；无复制双持、隔墙接球或跨图直接得分。

### T04 首批三个可复述连锁

- [ ] **空投传球**：队友同意弹送后在空中接到核心；对手可预判落点截球。
- [ ] **核心拔河**：双方吸附同一松散核心时进入短暂拔河；位置、遮挡和时机决定结果，不靠连点。
- [ ] **假传球骗招**：拟像可表演接球/带球动作但不能持有或得分；命中或近距观察可识破。
- 验收：每个连锁均有触发日志、可见反馈、服务器裁定和至少一种明确反制；不能随机直接判胜。

## P1：角色、Bot 与地图形成完整一局

### T05 三个角色原型数据化

- [-] 潜相者已有功能原型；仍需角色配置、近距折射/入口波纹和正式反制提示。
- [ ] 回弹者：蓄力定向脉冲，可截核心、推敌或配合弹送队友。
