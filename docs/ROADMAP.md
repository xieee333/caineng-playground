# 彩能游乐场开发路线

## 当前基线

- 仓库：`D:\project\caineng-playground`
- 已完成：PvP 设计规格、第一版垂直切片计划、v1–v11 概念图迭代。
- 当前美术基线：v11 波普漫画 2D，人物更酷，背景保持扁平 2D。
- 当前技术状态：尚未建立 Unity 工程，先以设计和视觉资产锁定方向。
- 当前阶段：M1 武器方向设计，等待用户审阅后进入概念板制作。

## 里程碑

### M0：方向冻结（已完成）

产出：

- 六人低竞技混战的核心玩法规格。
- 彩能移动、非致命互动、公共目标和狂欢事件规则。
- 波普漫画 2D 美术基线与 v11 概念图。
- Unity 垂直切片的总体实现计划。

### M1：武器视觉与玩法规范（当前）

产出：

- 六把首发枪的外观、基础玩法和特殊技定义。
- 武器词条与三档变形规则。
- 每把枪的资产交付标准、建模路线和验收标准。
- 六把枪的武器概念板 v12。

完成门槛：

- 六把枪缩小后轮廓可区分。
- 每把枪都有不依赖精准瞄准的环境或移动效果。
- 用户确认武器方向后，才进入 Unity 预制体实现。

### M2：第一把枪垂直切片

产出：

- 棱花喷绘器第一人称占位模型。
- 喷射彩能、弹跳表面、短时滞空和盛放特殊技。
- 枪械命中反馈、音效占位和基础 HUD。

完成门槛：

- 玩家能在 30 秒内学会喷射、跳跃和使用盛放。
- 不需要精确瞄准也能铺路、弹跳或干扰目标。

### M3：核心移动与非致命互动

产出：

- 液态、弹跳、飘浮三种彩能表面。
- 泡泡化与 3 秒重生。
- 击退、吸附、冻结、绑缚和道具掉落的规则层。
- 玩家和 Bot 使用同一套移动接口。

完成门槛：

- 单机测试场景可以连续移动、喷射、潜入、弹跳和滞空。
- 所有强控都能结束，不会软锁玩家。

### M4：六把枪接入

产出：

- 六个 `WeaponDefinition` 数据资产。
- 六个枪械预制体、投射物和特效占位。
- 每把枪一组 EditMode 规则测试。

完成门槛：

- 六把枪的玩法差异明显。
- 每把枪至少触发一种环境连锁。
- 枪械参数不写死在角色脚本中。

### M5：一张可玩的 6 人混战地图

产出：

- 中央广场、墙面路线、地下短隧道、弹跳平台和公共目标区。
- 五个 Bot、公共目标、欢乐值、狂欢槽和三种狂欢事件。
- 结算称号、基础音效和 HUD。

完成门槛：

- 一局 6–8 分钟可完整跑通。
- 玩家被泡泡化后约 3 秒内重返场地。
- 非第一名玩家也能获得有意义的正向称号。

### M6：视觉统一与试玩修正

产出：

- 六把枪的低模或 2D 分层资产。
- 角色动作、枪械动画、网点材质、漫画面板和统一 VFX。
- 面向新手的命中辅助、提示和节奏调整。

完成门槛：

- 远距离能认出角色和枪械。
- 画面不依赖写实 3D 才成立，整体保持 2D 波普观感。

### M7：网络化与构建

产出：

- 玩家位置、表面状态、道具状态和互动结果的网络同步。
- 房间创建、重连、结算和构建配置。

进入条件：

- M5 的本地玩家 + Bot 循环稳定。
- 玩法不再依赖临时改规则才能维持乐趣。

## 下一步执行顺序

1. 用户审阅 `docs/superpowers/specs/2026-09-18-caineng-playground-weapon-direction-design.md`。
2. 生成六把枪的 v12 波普漫画概念板。
3. 为六把枪分别生成轮廓板和第一人称视图。
4. 把棱花喷绘器做成第一个 Unity 可玩武器。
5. 通过测试后，再按星环吸尘炮、涂鸦缝线枪、气球鲸炮、反弹纸刃炮、烟花锦鲤炮的顺序接入。

## 提交与进度规则

- 每完成一个里程碑就更新 `docs/PROGRESS.md`。
- 每个独立可验证的资产或功能使用一次 Git 提交。
- 每次提交前运行对应的检查命令，并在进度文件记录结果。
- 概念图和实现资产都保留版本号，不覆盖旧稿。
